# docs/latest (generated outputs)

This folder is **runtime output** for the Seyd‑Yaar pipeline.

✅ The repo includes only:
- `meta_index.json` (may be empty)
- `preview.png` (placeholder)
- this README

Your pipeline should write runs under:

```
.../docs/latest/runs/<run_id>/variants/<variant>/species/<species>/meta.json
```

When `meta_index.json` contains at least one run, the PWA will automatically load it.
